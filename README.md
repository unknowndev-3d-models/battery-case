## 1. Summary

Battery case for:

| Type        | Quantity |
| ----------- | -------- |
| LR03        | 93       |
| LR6         | 30       |
| LR14        | 3        |
| LR20        | 3        |
| 6LR61       | 4        |
| CR2032      | 9        |
| CR2025      | 10       |
| CR2016      | 11       |
| CR2450      | 7        |
| CR1220      | 9        |
| LR44 (AG13) | 6        |

To build the case you need 4 pairs (8 pcs) _6 x 3 (mm)_ neodymium disc magnets.
